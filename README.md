# 🛒 Shopping Web Application (React)

## 📌 Overview
This is a simple and responsive Shopping Web Application built using React. It allows users to browse products, add them to the cart, and view total price dynamically.

---

## 🚀 Features
- 🛍️ Product Listing with Images  
- ➕ Add to Cart functionality  
- ❌ Remove from Cart  
- 💰 Dynamic Total Price Calculation  
- 📱 Responsive UI  

---

## 🛠️ Tech Stack
- React.js  
- JavaScript  
- HTML  
- CSS

## ▶️ How to Run

1. Clone the repository:
git clone https://github.com/your-username/shopping-app.git

2. Navigate to project:
cd shopping-app

3. Install dependencies:
npm install

4. Run the project:
npm run dev
